# Study Sessions Dataset

This dataset contains 1000 student study session records for use with File Search in Microsoft Foundry agents.

## Dataset Overview

| Attribute | Value |
|-----------|-------|
| Total Records | 1000 |
| Date Range | 2024-2026 |
| Students | 15 |
| Subjects | 6 (Biology, Chemistry, Physics, Math, History, Computer Science) |

## Column Descriptions

| Column | Description |
|--------|-------------|
| SessionID | Unique identifier (SS-00001 to SS-01000) |
| Date | Date of study session |
| StudentName | Student name |
| Subject | Subject studied |
| Topic | Specific topic within subject |
| StudyMethod | Learning method (Flashcards, Practice Problems, Reading, etc.) |
| DurationMinutes | Session length (15-180 minutes) |
| Difficulty | Self-reported difficulty (Easy, Medium, Hard) |
| QuizScore | Post-session quiz score (50-100, may be empty) |
| NotesPages | Number of notes pages created |
| FocusRating | Self-reported focus level (1-10 scale) |
